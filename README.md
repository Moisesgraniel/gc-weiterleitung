# Weiterleitung gentlemansconcierge.at

Leitet die Hauptdomain `gentlemansconcierge.at` (ohne www) auf `https://www.gentlemansconcierge.at` weiter, Pfad und Parameter bleiben erhalten.

Übergangslösung, solange das DNS der Domain bei Wix liegt. Die eigentliche Website liegt bei Cloudflare Pages.
Kann gelöscht werden, sobald die Domain bei Cloudflare ist.
